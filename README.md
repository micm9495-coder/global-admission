# Global Admission

Независимый гид по поступлению в зарубежные университеты для школьников:
24 экзамена, 100 университетов мира и 877 направлений с ориентирами стоимости
и требованиями к аттестату.

Автор проекта: Король Иван.

## Что внутри

- **129 статических страниц.** Отдельная страница у каждого вуза (`/universities/oxford/`) и экзамена (`/exams/ielts-academic/`), поэтому их находят поисковики.
- **Данные отдельно от кода.** JSON в `src/data/`, схемы в `src/content.config.ts`. Сборка падает, если у вуза нет страны, у программы нет вуза или ссылка битая по формату.
- **«Мой список».** Закладка на карточке вуза добавляет его в личный список (`/my/`): статус поступления, заметки и таблица сравнения. Хранится в браузере, без регистрации.
- **Минимум JavaScript.** Страницы рендерятся при сборке, скрипты только фильтруют уже готовые карточки, переключают вкладки и строят таблицу направлений.
- **Оптимизированные фото.** `astro:assets` пережимает снимки кампусов в WebP нескольких размеров.

## Стек

[Astro](https://astro.build) 7 · TypeScript (strict) · Zod-схемы контент-коллекций · Vitest · GitHub Actions → GitHub Pages.

## Структура

```
src/
  data/            JSON: universities, programs, exams, countries, meta
  content.config.ts  схемы и связи между коллекциями
  lib/             чистые функции: поиск, тексты, ссылки, оценки (покрыты тестами)
  components/      карточки, вкладки, шкала баллов, полоса рейтингов, фото кампуса
  layouts/Base.astro  шапка, подвал, мета-теги
  pages/           главная, каталоги, детальные страницы, /data/programs.json
  styles/global.css   дизайн «тетрадь в клетку»
  assets/          шрифты и фото кампусов
tests/             unit-тесты и проверки целостности данных
scripts/           одноразовый перенос данных из старой версии
```

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm test         # unit-тесты
npm run build    # проверка типов + сборка в dist/
```

## Как обновлять данные

- **Вуз, экзамен, программа:** правь нужный файл в `src/data/`. Поле `id` — это адрес страницы.
- **Фото кампуса:** `NODE_USE_ENV_PROXY=1 node scripts/find-campus-photos.mjs --download /tmp/cand` ищет на Wikimedia Commons снимки под свободной лицензией для вузов без фото и складывает превью для просмотра. Посмотри их и поставь выбранные: `node scripts/install-campus-photo.mjs <id вуза> <номер кандидата> --cache /tmp/cand`. Скрипт сохранит `src/assets/campus/<id>.jpg` и запишет автора и лицензию в `src/data/photos.json`; подпись появится под фото и на странице `/photos/`. Без файла показывается заглушка с названием.
- **Стоимость обучения:** только с официальных сайтов вузов. Запиши тариф, год, источник и, если вуз его публикует, бюджет или оценку расходов на жизнь в `data-updates/official-costs.json`, затем выполни `node scripts/apply-official-costs.mjs`. Скрипт обновит вуз и строки программ, где ещё стояла расчётная оценка, и поставит дату проверки. Тест не даст пометить стоимость проверенной, если источник лежит не на домене вуза. Если вуз цифру не публикует, поле остаётся пустым («вуз не публикует»), своей оценкой его не заполняем.

## Деплой

Workflow `.github/workflows/deploy.yml` на каждый push в `main` запускает тесты, собирает сайт и публикует его на GitHub Pages. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

## История

До версии 15 проект был одним HTML-файлом на 5 МБ: данные, патчи версий и base64-фото внутри. `scripts/extract-legacy.cjs` открыл старую версию в браузере и выгрузил все данные в JSON, включая частные случаи, которые раньше были зашиты в код (`if (i === 2) …`). Теперь это поля в данных.
